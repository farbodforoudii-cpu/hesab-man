# «حساب من»: پروندهٔ پروژه

پروندهٔ ثابت پروژه: وضعیت، تصمیم‌ها، یافته‌های ممیزی و سؤال‌های باز. **هیچ دادهٔ مالی یا نام شخصی در این فایل نیست.**

## پروفایل
- **هدف:** اپ مالی شخصی یک نفر؛ ثبت سریع روی آیفون، دیدن وضع ماه، تحلیل رفتار مالی، و پیشنهاد زمان و مقدار خرید دلار، یورو، طلا و نقره در شرایط تورم بالای ایران.
- **کاربر:** فقط صاحب حساب (خریدار؛ فروش دارایی در برنامه نیست).
- **فناوری:** PWA آفلاین، جاوااسکریپت خالص، IndexedDB، همگام‌سازی Supabase با کد ۲۵ حرفی (سرور فقط هش آن را دارد)، GitHub Pages.
- **منبع‌ها:** صورت‌حساب بلو (منبع اصلی برای تطبیق)، ثبت‌های دستی، «زندگی من» (پیش‌بینی درآمد کاری)، tgju (قیمت‌ها و انس جهانی)، تحلیل خودکار شرایط ایران (data/macro.json، دو بار در روز).

## اعتبارسنجی
- `tests/core.test.mjs`: تقویم، قالب اعداد، جمع ماه، موجودی، EMA/RSI، قیمت زنده، حباب، سیگنال. اجرا: `TZ=Asia/Tehran node --test tests/*.test.mjs`. روی هر push در GitHub Actions (`tests.yml`).
- **تطبیق با بانک:** هر صورت‌حساب بلو قلم‌به‌قلم با اپ تطبیق داده می‌شود؛ اختلاف باید صفر یا دقیقاً توضیح‌داده‌شده باشد. فایل خام بعد از تطبیق پاک می‌شود.
- **قبل از هر تغییر ظاهری:** عکس از گوشی و آیپد، شیشه‌ای و تیره، بدون خطای کنسول؛ انتشار فقط بعد از تأیید صاحب حساب.
