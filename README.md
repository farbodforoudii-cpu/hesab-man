# حساب من — Finance OS

اپ مالی شخصی، آفلاین و نصب‌شدنی (PWA) برای آیفون و آیپد.

- ثبت تراکنش با «مبلغ + یک لمس» از روی پیشنهادهای یادگرفته‌شده
- تاریخ شمسی، مبلغ به تومان با نمایش حروف
- واردکردن اکسل صورت‌حساب بلوبانک و جفت کردن خودکار با ثبت‌های دستی
- داشبورد: درآمد کاری، حمایت خانواده، خرج واقعی، مازاد، طلب و دارایی
- همهٔ داده‌ها فقط روی دستگاه (IndexedDB)؛ پشتیبان JSON برای انتقال به آیپد

**هیچ دادهٔ مالی‌ای در این مخزن نیست.** داده‌ها فقط روی دستگاه و در فایل‌های پشتیبان خود کاربر هستند.

اجرا به‌صورت محلی: `python3 -m http.server` داخل همین پوشه.
